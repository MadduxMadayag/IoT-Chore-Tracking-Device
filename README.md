# IoT Chore Tracking Device with Discord Integration

![Alt Text](Pictures/Chore_Tracker.jpg)

## Overview

Chore Tracker is a smart home device designed to help roommates stay organized by making chore assignments visible, interactive, and easy to manage. Instead of relying on sticky notes or text messages, roommates interact with a physical tabletop display synchronized with a Discord bot. Chores can be assigned digitally while the custom-built hardware provides an always-visible reminder inside the home. The project combines embedded systems, PCB design, CAD, Python development, and Discord API integration into a single product.
